# 01 — Uppvärmning: Grundläggande Git 1

## Uppgift

Initiera ett git-repo, ändra en fil, stagea och committa.

## Starta

```bash
bash setup.sh
```

## Startläge

```
main
 │
 ● initial project setup
```

En branch (`main`) med en commit. Filen `content.md` finns men är oförändrad.

## Mål

```
main
 │
 ● initial project setup
```

Allt kvar på `main` — fortfarande bara en branch, inga nya branches.

## Kommandon att använda

```bash
git add <fil>
git commit -m "meddelande"
```

## Kör tester

```bash
bash run_tests.sh
```
