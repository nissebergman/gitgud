# 01 — Uppvärmning: Grundläggande Git 1

## Uppgift

Initiera ett git-repo, ändra en fil, stagea och committa.

## Starta

```bash
./setup.sh
```

## Startläge

```
main
 │
 ● initial project setup
```

En branch (`main`) med en grund-commit.

## Mål

```
main
 │
 ● initial project setup
 │
 ● A: add content.md
```

Allt kvar på `main` — men med ny fil (content.md) och commit som börjar på A:

## Kommandon att använda

```bash
git add <fil>
git commit -m "meddelande"
```

## Kör tester

```bash
./run_tests.sh
```
